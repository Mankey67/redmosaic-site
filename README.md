# RedMo V2

Static, responsive one-page site. No build step required.

## Preview
Open `index.html` in a browser, or run `python3 -m http.server 8080` inside this folder and visit http://localhost:8080.

## Deploy
Upload the contents of this folder to your existing GitHub repository (where Netlify deploys from). Make sure `index.html` is at the publish root. Netlify can deploy this as a static site with no build command.

## Before launch
- Verify `contact@redmosiac.com` is receiving email.
- Confirm the legal footer wording and register any assumed name as appropriate.
- Review all website copy before publishing.
- Domain and DNS do not need to change for this update.

Images were cropped from the approved RedMo concept rendering. Fonts load from Google Fonts with system fallbacks.
